What You'll Do

  • Deploy Camunda 8 Self-Managed on Kubernetes.
  • Learn Helm-based installation and configuration.
  • Access Operate, Tasklist, Identity and other platform components.
  • Understand namespaces, ingress, storage and cloud networking.
  • Gain rich experience using a real Kubernetes cluster, before taking the Camunda 8 Kubernetes Architect Practice Test (Udemy course).

Free Lab Access

Every Udemy student is given access to a dedicated namespace in a Kubernetes cluster (GKE). The free subscription provides temporary access (6-Hours) to a shared learning environment designed specifically for educational purposes.

On the Sign In page, use Email / OTP method to gain access to c8-labs environment.
