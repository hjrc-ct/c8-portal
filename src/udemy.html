c8-labs

Welcome, Udemy Students!

Thank you for enrolling in the Camunda course. This complimentary lab environment lets you deploy and explore Camunda 8 on Google Kubernetes Engine without setting up your own cloud infrastructure.

What You'll Do

  • Deploy Camunda 8 Self-Managed on Kubernetes.
  • Learn Helm-based installation and configuration.
  • Access Operate, Tasklist, Identity and other platform components.
  • Understand namespaces, ingress, storage and cloud networking.
  • Gain rich experience using a real Kubernetes cluster, before taking the Camunda 8 Kubernetes Architect Practice Test (Udemy course).

Free Lab Access

Every Udemy student is given access to a dedicated namespace in a kubernetes cluster environment (GKE). The free subscription provides temporary access (6-Hours) to a shared learning environment designed specifically for educational purposes.

On Sign In page, use Email / OTP method to gain access to c8-labs environment.

Before You Begin

  • Follow the guided steps inside the portal.
  • Complete the deployment labs to gain Camunda 8 installation and configuration experience.
  • Take the Practice Exam / Udemy course.

Need Help?

If you encounter any technical issues with the c8-labs environment, or have questions about Practice Exam, please use the Udemy Q&A section so that other students can benefit from the discussion.
